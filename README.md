# 装甲板灯条识别项目

## 实现思路

先用 `VideoCapture` 逐帧读取视频，将图像转成灰度图，通过亮度阈值保留较亮的区域。同时计算红色通道与蓝色通道的差值，筛选红色区域。将两个结果取交集，再做闭运算，得到灯条的二值掩码。

接着使用 `findContours` 提取轮廓，用 `minAreaRect` 拟合旋转矩形，根据面积、长度、长宽比和倾角筛选灯条。取矩形两条短边的中点作为灯条端点，并根据 y 坐标区分上下端点。

最后根据两根灯条的长度、倾角、高度差和间距进行配对，按左上、右上、右下、左下的顺序连接四个端点。输出视频左侧为识别结果，右侧为二值掩码，方便观察和调试。

## 调试中遇到的问题

最初绿色框主要出现在视频中间，部分开头画面没有检测到灯条。目标较远时灯条很细，亮度筛选后保留下来的区域较少。降低亮度阈值后，观察到较小目标也能够被识别，绿色框出现的时间变长。

视频中还有地面反光。降低阈值有助于保留灯条，也会保留更多反光，因此不能只靠降低阈值解决漏检。第 18 帧的掩码中仍能看到反光，但最终只输出了两根候选灯条和一个装甲板框。其他帧是否存在误检，还需要继续检查。
